# Historical design and implementation archive

Everything in this directory is historical. The specs and plans document how
shipped features were designed and built; they are not current backlog and must
not be executed mechanically against the current tree.

- `specs/` contains design decisions and rejected alternatives.
- `plans/` contains implementation instructions tied to older source layouts.

Current authority lives one level up:

- [`../README.md`](../README.md) — documentation index and shipped state;
- [`../trance-pass-spec.md`](../trance-pass-spec.md) — active roadmap;
- [`../tokenizer-spec.md`](../tokenizer-spec.md) — current focused implementation
  draft;
- [`../skim-product-philosophy.md`](../skim-product-philosophy.md) — product
  principles.

Historical files keep their original detailed language so past decisions remain
auditable. Their status banners supersede unchecked task boxes, old constants,
and references to earlier UI structures.
